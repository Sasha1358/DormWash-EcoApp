# DormWash 🍃

**DormWash** — це екологічний мобільний застосунок для запису на пральні машини у студентському гуртожитку. Основна мета проєкту полягає у збереженні ресурсів (води та електроенергії) шляхом автоматизації та оптимізації рутинного процесу прання. 

Завдяки вбудованому ШІ-помічнику, додаток аналізує параметри одягу та генерує рекомендації щодо оптимального еко-режиму, температури та точного дозування прального засобу.

**Основний функціонал:**
* **Безпечна авторизація:** Доступ до системи дозволено виключно студентам через пошту домену @lpnu.ua.
* **ШІ-помічник еко-прання:** Підбір екологічних налаштувань пралки (температура, режим, об'єм хімії) на основі введених характеристик тканини та рівня забруднення.
* **Динамічне бронювання:** Перегляд статусу вільних машин у реальному часі та бронювання тайм-слотів, які адаптуються під тривалість згенерованого ШІ-режиму.
* **Eco-Tracker (Екологічні метрики):** Відстеження індивідуальної статистики зекономленої води та електроенергії у профілі користувача.
* **Розумні Push-сповіщення:** Нагадування про наближення заброньованого часу, завершення циклу прання та необхідність очищення фільтрів.

**Про проєкт:**
Розробляється в рамках курсу "Програмування мобільних додатків". 
Напрямок індустрії: Екологія (GreenTech).
