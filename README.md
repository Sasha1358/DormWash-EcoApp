# DormWash 🍃

DormWash — це екологічний мобільний застосунок для запису на пральні машини у студентському гуртожитку. Основна мета проєкту полягає у збереженні ресурсів (води та електроенергії) шляхом автоматизації та оптимізації рутинного процесу прання.

Завдяки вбудованому ШІ-помічнику, додаток аналізує параметри одягу та генерує рекомендації щодо оптимального еко-режиму, температури та точного дозування прального засобу.

## Реалізований MVP (Лабораторна робота 2)
У поточній версії реалізовано основний функціональний сценарій: користувач вводить характеристики тканини в мобільному додатку, дані відправляються на бекенд, де інтегрована модель ШІ (Gemini 3.5 Flash Lite) розраховує екологічні параметри прання та повертає їх для відображення.

### Технологічний стек
*   **Mobile:** Android (Kotlin), Retrofit, Coroutines, Gson.
*   **Backend:** Python 3.10+, FastAPI, Pydantic, python-dotenv.
*   **AI:** Google Gemini API.

## Інструкція із запуску (Backend)

1. **Створіть та активуйте віртуальне середовище:**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для Mac/Linux:
   # source venv/bin/activate
2. **Встановіть залежності:**
 pip install -r requirements.txt
3. **Налаштуйте змінні середовища:**
   Створіть файл .env у кореневій папці та додайте свій ключ API
   EMINI_API_KEY=ваш_ключ_google_gemini
3. **Запустіть сервер:**
   uvicorn main:app --host 0.0.0.0 --port 8000 --reload

## Доступні API Ендпоінти
 GET /health — перевірка статусу сервера.

POST /api/eco-mode — генерація ШІ-рекомендацій для прання.

Приклад запиту: {"fabric_type": "бавовна", "color": "білий", "dirt_level": "сильне"}

Приклад відповіді: {"temperature": 60, "spin_speed": 1000, "duration_minutes": 90, "detergent_ml": 50, "ai_explanation": "Для білої бавовни та сильних забруднень оптимально використовувати температуру 60С для ефективного розщеплення бруду без зайвих енерговитрат"}

Swagger UI доступний за адресою: http://localhost:8000/docs

## Інструкція із запуску (Mobile)
Відкрийте проєкт в Android Studio.

Переконайтеся, що комп'ютер та Android-емулятор знаходяться в одній мережі (в API-клієнті Retrofit вказана локальна IP-адреса сервера).

Натисніть "Run" (Shift + F10) для запуску застосунку на емуляторі або підключеному фізичному пристрої.

## Обмеження поточної версії
База даних: Дані поки що не зберігаються в повноцінну БД (Supabase буде підключено на наступних етапах).

Авторизація: Вхід через корпоративну пошту @lpnu.ua ще не імплементовано в поточному MVP.

Мережа: Додаток залежить від локальної роботи сервера, для публічного релізу потрібен деплой бекенду на хмарний хостинг.
