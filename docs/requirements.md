# Вимоги (Requirements)

**Реалізовані вимоги (MVP):**
- Мобільний клієнт з формою вводу даних про одяг.
- Backend на FastAPI з валідацією Pydantic.
- Інтеграція з Google Gemini API для генерації параметрів прання.
- Відображення результатів (температура, віджим, час, засіб, пояснення) у мобільному інтерфейсі.
- Базова обробка помилок (валідація, відсутність мережі, помилки ШІ).

**Незавершені функції (Технічний борг):**
- Авторизація користувачів виключно через домен `@lpnu.ua`.
- Збереження історії прання у базі даних (Supabase).
- Система реального часу для бронювання вільних пральних машин.

**Критерії готовності MVP:** Мобільний додаток успішно надсилає HTTP-запит, backend обробляє його через ШІ та повертає JSON, а UI коректно відображає дані без аварійних завершень.
