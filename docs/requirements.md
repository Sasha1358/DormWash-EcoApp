# Вимоги (Requirements)

**Реалізовані вимоги (Лаб 2–4):**
- Мобільний клієнт з формою вводу даних про одяг (тип, колір, забруднення, вага) та клієнтською валідацією.
- Backend на FastAPI з валідацією Pydantic.
- Інтеграція з Google Gemini API для генерації параметрів прання з урахуванням ваги.
- Локальне збереження історії запитів і результатів у SQLite (`dormwash_history.db`) із збереженням після перезапуску.
- Екран історії (зворотний хронологічний порядок, порожній стан), екран деталей, видалення одного запису та очищення історії з підтвердженням.
- Підвищений рівень: збереження запитів без доступу до сервера зі статусом `очікує`, ручна повторна відправка, життєвий цикл статусів (`очікує` / `надсилається` / `готово` / `помилка`) та захист від одночасного дублювання.

**Незавершені функції (Технічний борг):**
- Авторизація користувачів через домен `@lpnu.ua`.
- Хмарна синхронізація історії прання між пристроями (Supabase).
- Система реального часу для бронювання вільних пральних машин.
- Автоматизовані тести (pytest / Android unit-тести).
