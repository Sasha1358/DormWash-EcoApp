# AI Компонент (AI Component)

**Призначення:** Аналіз типу тканини, кольору, рівня забруднення та ваги одягу для підбору максимально екологічних (економних) параметрів прання без шкоди для одягу.
**Використана модель:** `gemini-3.5-flash-lite`.
**Формат даних та логіка:** Модель отримує текстовий prompt з інструкцією. Вага одягу впливає на кількість засобу (`detergent_ml`) та тривалість циклу (`duration_minutes`), але не підвищує температуру. Відповідь повертається ТІЛЬКИ у форматі JSON.
**Обмеження та очищення:** Модель може додавати маркдаун-теги (```json). На стороні backend реалізовано примусове очищення (відрізання тегів) перед парсингом.
**Fallback:** Якщо ШІ повертає невалідний JSON, backend перехоплює `JSONDecodeError` і повертає клієнту статус 502. Додаток показує текст помилки, не завершуючи роботу.
