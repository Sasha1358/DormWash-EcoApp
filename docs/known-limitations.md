# Відомі обмеження (Known Limitations)

- **Зберігання секретів:** API-ключ Gemini зберігається локально у файлі `.env` на бекенді й не передається на клієнт.
- **Локальність історії:** Дані історії прання зберігаються виключно в локальній базі SQLite на пристрої користувача; хмарна синхронізація між пристроями відсутня.
- **Мережева залежність:** Бекенд працює локально. Для тестування на емуляторі або фізичному пристрої потрібно підтримувати актуальну IP-адресу в `ApiClient.BASE_URL`.
- **Наближеність рекомендацій:** Вага вводиться вручну, ШІ не знає реальної місткості конкретної пральної машини в гуртожитку; через особливості LLM рекомендації для однакових вхідних даних можуть незначно відрізнятися.
- **Ручна синхронізація черги:** Відкладені офлайн-запити зі статусом `очікує` надсилаються лише вручну користувачем (фонова автоматична синхронізація не реалізована).
