# Відомі обмеження (Known Limitations)

- **Зберігання секретів:** API-ключ Gemini зберігається локально у файлі `.env`.
- **Відсутність збереження стану:** MVP не має підключеної бази даних, тому історія прання не зберігається.
- **Мережева залежність:** Бекенд працює локально. Для тестування на реальному пристрої потрібно щоразу оновлювати IP-адресу комп'ютера у клієнті Retrofit.
- **Наближеність рекомендацій:** Вага вводиться вручну, ШІ не знає реальної місткості конкретної пральної машини в гуртожитку. Також, через особливості LLM, результати для однакових вхідних даних можуть злегка відрізнятися.
