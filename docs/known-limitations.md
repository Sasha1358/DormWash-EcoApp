# Відомі обмеження (Known Limitations)

- **Зберігання секретів:** API-ключ Gemini зберігається локально у файлі `.env`. У продакшені необхідно використовувати секрети хостинг-провайдера або менеджери секретів.
- **Відсутність збереження стану:** MVP не має підключеної бази даних, тому згенеровані рекомендації не зберігаються в історію користувача.
- **Мережева залежність:** Бекенд працює локально. Для тестування на реальному пристрої потрібно щоразу оновлювати IP-адресу комп'ютера у клієнті Retrofit.
