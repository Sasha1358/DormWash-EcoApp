# Тестування (Testing)

**Команди запуску:**
- Backend: `uvicorn main:app --host 0.0.0.0 --port 8000 --reload` (в середовищі `venv`).
- Mobile: Запуск через Android Studio на емуляторі.

**Сценарії ручного тестування (API та основний сценарій):**
1. **Успішний запит (мала/велика вага):** `бавовна`, 2 кг та `шовк`, 5 кг → повертається коректний JSON, збільшується доза засобу, температура не перевищує безпечну.
2. **Валідація на клієнті:** порожнє поле ваги або значення > 20 кг → помилка біля поля, запит не надсилається.
3. **Валідація на сервері:** порожня тканина → `400 Bad Request`; відсутні або невалідні поля → `422 Unprocessable Entity`. Помилка backend не зберігається в історію як готовий результат.

**Сценарії ручного тестування (Локальне сховище — Лаб 4):**
4. **Порожня історія:** при першому запуску екран історії показує повідомлення про відсутність записів.
5. **Хронологія та деталі:** після двох різних запитів новіший відображається зверху; натискання відкриває повні деталі запису.
6. **Перезапуск:** після повного закриття й повторного відкриття застосунку всі збережені записи залишаються в історії.
7. **Видалення:** видалення запису або очищення історії вимагає підтвердження в діалозі; видалені записи не повертаються після перезапуску.
8. **Офлайн-черга (підвищений рівень):** при вимкненому сервері запит зберігається зі статусом `очікує`.
9. **Помилка повтору та відновлення:** спроба відправки без сервера змінює статус на `помилка` із блокуванням подвійного натискання; після запуску сервера повторна відправка оновлює статус на `готово` і додає результат ШІ.
