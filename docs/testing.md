# Тестування (Testing)

**Команди запуску:**
- Backend: `uvicorn main:app --host 0.0.0.0 --port 8000 --reload` (в середовищі `venv`).
- Mobile: Запуск через Android Studio на емуляторі.

**Обов'язкові сценарії ручного тестування:**
1. **Успішний запит (мала вага):** Ввести "шовк", "чорний", "легке", вага "1". Очікується низька температура (~30°C) та мала кількість засобу.
2. **Успішний запит (велика вага):** Ті самі дані, але вага "6". Очікується більше засобу, але температура не підвищується.
3. **Дробове значення:** Введення "2,5" (з комою) успішно обробляється і відправляється як число 2.5.
4. **Помилка валідації на клієнті:** Порожнє поле ваги або значення поза межами (напр. 25) -> показує помилку біля поля, запит не йде.
5. **Помилка валідації на сервері:** Порожня тканина повертає `400 Bad Request`. Відсутні або некоректні дані в JSON повертають `422 Unprocessable Entity`.
6. **Недоступність сервера:** Вимкнути uvicorn. Натиснути кнопку в додатку. Очікується перехоплення помилки `Failed to connect` без крашу додатка.
