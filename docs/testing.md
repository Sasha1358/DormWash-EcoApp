# Тестування (Testing)

**Команди запуску:**
- Backend: `uvicorn main:app --host 0.0.0.0 --port 8000 --reload` (в середовищі `venv`).
- Mobile: Запуск через Android Studio на емуляторі (мережева адреса налаштована на локальний сервер).

**Обов'язкові сценарії ручного тестування:**
1. **Успішний запит:** Ввести "шовк", "чорний", "легке". Очікується температура ~30°C та низький віджим.
2. **Помилка валідації:** Залишити поле "Тип тканини" порожнім. Очікується помилка 400.
3. **Недоступність сервера:** Вимкнути uvicorn. Натиснути кнопку в додатку. Очікується перехоплення помилки `Failed to connect` без крашу додатка.
