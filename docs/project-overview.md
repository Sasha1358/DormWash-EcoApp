# Огляд проєкту (Project Overview)

**Проблема:** Нераціональне використання ресурсів (води та електроенергії) студентами у гуртожитках під час прання через незнання оптимальних режимів для різних типів тканин.
**Користувач:** Студент Національного університету "Львівська політехніка", який проживає в гуртожитку.
**Основний сценарій:** Користувач вводить характеристики одягу (тип тканини, колір, рівень забруднення) у мобільний додаток. Додаток звертається до ШІ-помічника, який генерує оптимальні екологічні налаштування пральної машини, і виводить їх на екран.
**Межі MVP (Лабораторна 2):** Реалізовано виключно потік генерації еко-режиму через ШІ. Бронювання пральних машин, бази даних та авторизація винесені за межі поточного MVP.
