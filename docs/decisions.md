# Прийняті рішення (Architecture Decisions)

1. **Мова мобільної розробки - Kotlin:** Обрано для забезпечення нативної продуктивності та зручної роботи з асинхронними запитами через Coroutines.
2. **Фреймворк Backend - FastAPI (Python):** Обрано через високу швидкість розробки, вбудовану підтримку асинхронності та автоматичну валідацію даних і генерацію документації (Swagger) за допомогою Pydantic.
3. **AI Модель - Gemini 3.5 Flash Lite:** Обрано через оптимальний баланс швидкості генерації та точності структурування JSON, що критично для миттєвої відповіді в мобільному інтерфейсі[cite: 23].
