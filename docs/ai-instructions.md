# Інструкції для AI (Coding Agent Rules)

1. Перед змінами прочитати документацію з папки /docs та перевірити структуру репозиторію.
2. Спочатку пояснити поточну реалізацію та запропонувати план.
3. Перерахувати файли, які потрібно змінити.
4. Не переписувати весь проєкт для локальної задачі.
5. Не змінювати API-контракт без пояснення та оновлення документації.
6. Не додавати залежності без обґрунтування.
7. Не зберігати секрети в коді, prompts або Git.
8. Додати або оновити тести для нової поведінки.
9. Після реалізації підсумувати зміни, перевірки та відомі ризики.
